# Waseda Moodle Plus

Waseda Moodle を使いやすくするブラウザ拡張機能です（Chrome・Edge などの Chromium 系ブラウザと Firefox に対応）。
[Better Waseda Moodle](https://github.com/mkihr-ojisan/better-waseda-moodle)（MIT License）を参考に作り直しました。ビルドは不要で、このフォルダをそのままブラウザに読み込めます。

## ダウンロード

このページの緑の「Code」ボタン →「Download ZIP」でダウンロードし、展開します（`waseda-moodle-plus-main` フォルダができます）。
展開したフォルダは、拡張機能を使っている間は消さずに置いておいてください。

## インストール（Chrome・Edge・Brave など）

1. `chrome://extensions`（Edge は `edge://extensions`）を開く
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ（`manifest.json` があるフォルダ）を選ぶ
4. 設定画面が開くので、必要な機能をオン・オフする

ファイルを編集・更新したら、`chrome://extensions` でこの拡張機能の再読み込みボタン（↻）を押してください。

## インストール（Firefox 128 以降）

1. `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」を押し、展開したフォルダの `manifest.json` を選ぶ
3. 設定画面が開くので、必要な機能をオン・オフする（「サイトへのアクセスを許可してください」と出たら許可する）

この方法は Firefox を再起動すると外れます。ずっと使うには、Mozilla の署名を受けた `.xpi` ファイルを使ってください。

## 設定・データの保存場所

設定はブラウザの中にだけ保存され、別のパソコンやブラウザとは同期されません。設定画面の書き出し・読み込みで移せます（ログイン情報は含まれないので、移した先で入れ直してください）。

## 機能

| 分類 | 機能 |
| --- | --- |
| 課題一覧 | アイコンをクリックすると締切が近い課題・小テストを一覧表示（検索・種類で絞り込み、非表示）、アイコンに件数バッジ、締切前のデスクトップ通知 |
| 時間割 | ダッシュボードに曜日×時限の時間割を表示。今日・今の時限を強調、科目ごとの未提出課題数、色・表示名・メモ・教室の編集。シラバスから曜日・時限・教室を自動取得、シラバスのページから「時間割に追加」 |
| 自動ログイン | ログインページを開くと保存した ID・パスワードで自動ログイン。Microsoft のサインイン画面に「自動ログインを有効にする」チェックボックスを追加。MyWaseda・成績照会・科目登録・Waseda メールをアイコンの右クリックメニューから開く |
| デザイン | 旧デザイン（今までの見た目）と新デザインを、設定画面またはヘッダーのボタンで切り替えられます。新デザインでは、上のタブを左の縦メニューに移し、その下に今学期の科目を時間割の順に並べます。どのページからも締切の一覧を引き出せて、Ctrl+K で科目・締切・ページをまとめて探せます。ダッシュボードには今日の授業（時限ごとの帯）と7日間の締切を出します。マイコースは曜日・時限順の一覧、カレンダーは月の表とその日の授業・予定、ホームのお知らせは1件1行の掲示板、コースページには検索と種類の絞り込みが付きます。どのページも「Moodle の表示」で元に戻せます |
| 外観 | Moodle のダークモード（専用テーマ／色反転、常に／システムに合わせる）、見た目を整える CSS、余白の削減、右下ボタン・通知バッジの非表示 |
| 小テスト | 残り時間を右下に大きく固定表示、未解答の問題がある状態で次へ進むときに確認 |
| 課題の提出 | 送信前にセッション切れを確認、セッションの自動延長、提出時の注意事項に自動チェック、文字数カウンター、提出ファイル名の自動変更 |
| その他 | ファイルをダウンロードせずブラウザで開く、動画のイントロをスキップ、戻る・進むの高速化、シラバスのリンク修正、成績照会メニューの待ち時間解消、IntelliBoard の記録を送らない、設定のバックアップ・復元 |

## 構成

```
manifest.json          拡張機能の定義（Manifest V3）
background.js          Service Worker の入口。各画面からのメッセージを処理
bg/                    Moodle API・ログイン・シラバス・バッジ・機能の切り替え
offscreen/             HTML の解析（Service Worker には DOMParser が無いため）
lib/                   設定のデフォルト値や共通の部品（全画面で共有）
content/               Moodle・シラバス・ログイン画面で動くスクリプト
content/main-world/    ページ側で動かす必要のあるスクリプト
popup/ options/ pages/ ポップアップ・設定画面・自動ログイン／ランチャー画面
styles/                共通部品・ダークモード・スタイル修正の CSS
rules/                 ネットワークルール（declarativeNetRequest）
```

## 注意

- 早稲田大学の公式ツールではありません。Moodle・シラバス・ログイン画面の仕様が変わると、一部の機能が動かなくなることがあります。
- 自動ログイン用のパスワードは、この PC の Chrome の拡張機能ストレージに暗号化せずに保存されます。共用 PC では使わないでください。多要素認証が求められる場合は自動ログインできません。
